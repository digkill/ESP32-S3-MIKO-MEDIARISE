# Интеграция кастомной модели wake word

## Автоматическое обнаружение

Проект автоматически обнаруживает кастомные модели wake word в директории `models/custom_wake_word/`.

## Структура модели

Поместите вашу обученную модель следующим образом:

```
models/custom_wake_word/
└── my_model_name/
    ├── my_model_name.bin    # Бинарный файл модели (обязательно)
    └── model_config.json     # Конфигурация (опционально)
```

## Процесс сборки

1. **Обнаружение**: При сборке система автоматически ищет модели в `models/custom_wake_word/`
2. **Проверка**: Проверяется наличие файлов `.bin` в поддиректориях
3. **Упаковка**: Найденные модели упаковываются в `srmodels.bin`
4. **Интеграция**: Модели включаются в assets и загружаются при инициализации

## Логи сборки

При обнаружении кастомных моделей вы увидите:

```
Found 1 custom wake word model(s)
  custom wake word models: my_model_name (will be packaged)
```

## Требования к модели

- Формат: Бинарный файл `.bin`, совместимый с ESP-SR SDK
- Размещение: В поддиректории `models/custom_wake_word/<model_name>/`
- Имя файла: Может быть любым, но должен иметь расширение `.bin`

## Настройка wake word type

В `menuconfig` выберите:
- **Wakenet model with AFE** (для ESP32-S3) - рекомендуется
- **Wakenet model without AFE** (для других чипов)

Кастомные модели работают с обоими типами.

## Отладка

Если модель не загружается:

1. Проверьте логи при сборке - должна быть строка о найденной модели
2. Проверьте логи при запуске - ищите сообщения типа `"Wake word(...),freq: 16000"`
3. Убедитесь, что файл `.bin` находится в правильной директории
4. Проверьте совместимость модели с версией ESP-SR SDK
