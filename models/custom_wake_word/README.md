# Кастомные модели wake word

## Описание

Эта директория предназначена для размещения ваших кастомных моделей wake word.

## Структура

После обучения модели разместите файлы следующим образом:

```
models/custom_wake_word/
└── my_custom_wake_word/        # Директория с именем модели
    ├── my_custom_wake_word.bin # Бинарный файл модели (обязательно)
    └── model_config.json       # Конфигурация модели (опционально)
```

**Важно:** Каждая модель должна находиться в своей поддиректории, и в ней должен быть хотя бы один файл `.bin`.

## Формат model_config.json

Пример конфигурации:

```json
{
  "model_name": "my_custom_wake_word",
  "wake_word": "ваше_слово",
  "sample_rate": 16000,
  "chunk_size": 512,
  "description": "Описание модели"
}
```

## Интеграция в проект

1. Поместите файл `.bin` модели в эту директорию
2. Убедитесь, что модель совместима с версией ESP-SR SDK
3. Настройте wake word type в menuconfig
4. Соберите и прошейте проект

Подробные инструкции см. в `docs/custom-wake-word-training.md`.
