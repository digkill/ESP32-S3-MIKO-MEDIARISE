# Данные для обучения модели wake word

## Описание

Эта директория предназначена для хранения аудиоданных, используемых для обучения кастомной модели wake word.

## Структура

```
training_data/
├── wake_word/          # Записи вашего wake word
│   ├── sample1.wav
│   ├── sample2.wav
│   └── ...
├── background/         # Фоновый шум
│   ├── noise1.wav
│   └── ...
└── negative/          # Другие слова (не wake word)
    ├── other1.wav
    └── ...
```

## Требования к данным

### Wake Word (ваше ключевое слово)

- **Количество**: Минимум 100-200 записей
- **Дикторы**: Разные люди (мужчины, женщины, разные возрасты)
- **Условия**: Разные условия записи (тихо, громко, с шумом, разные расстояния)
- **Длительность**: 1-2 секунды на запись
- **Формат**: WAV, 16kHz, моно, 16-bit PCM

### Background (фоновый шум)

- **Количество**: 50-100 записей
- **Типы**: Различные типы фонового шума (белый шум, шум улицы, тишина, музыка на фоне)
- **Длительность**: 2-5 секунд на запись

### Negative (другие слова)

- **Количество**: 100-200 записей
- **Содержание**: Другие слова и фразы, которые НЕ являются вашим wake word
- **Разнообразие**: Разные слова, фразы, команды

## Подготовка данных

Используйте скрипт `scripts/wake_word_training/convert_audio.py` для конвертации аудио в нужный формат:

```bash
python scripts/wake_word_training/convert_audio.py wake_word_raw/ wake_word/
python scripts/wake_word_training/convert_audio.py background_raw/ background/
python scripts/wake_word_training/convert_audio.py negative_raw/ negative/
```

## Советы по сбору данных

1. **Разнообразие дикторов**: Чем больше разных людей, тем лучше
2. **Разные условия**: Записывайте в разных местах и условиях
3. **Естественность**: Записи должны звучать естественно
4. **Качество**: Избегайте искажений и артефактов
5. **Баланс**: Старайтесь иметь примерно равное количество записей в каждой категории
