# Инструкция по сборке и прошивке для платы esp32-s3-touch-lcd-1.46

## Что было сделано

✅ Конфигурация проекта обновлена для использования платы **esp32-s3-touch-lcd-1.46**
✅ В файле `sdkconfig` выбрана плата `CONFIG_BOARD_TYPE_WAVESHARE_S3_TOUCH_LCD_1_46`
✅ Создан скрипт `build_and_flash.sh` для автоматической сборки

## Способы сборки и прошивки

### Способ 1: Использование скрипта (рекомендуется)

1. **Настройте окружение ESP-IDF** (если еще не настроено):
   ```bash
   . $HOME/esp/esp-idf/export.sh
   # или путь к вашему ESP-IDF
   ```

2. **Запустите скрипт сборки**:
   ```bash
   ./build_and_flash.sh
   ```

3. **Прошивка** (после успешной сборки):
   ```bash
   idf.py flash monitor
   ```

### Способ 2: Ручная сборка через menuconfig

1. **Настройте окружение ESP-IDF**:
   ```bash
   . $HOME/esp/esp-idf/export.sh
   ```

2. **Установите целевой чип** (если нужно):
   ```bash
   idf.py set-target esp32s3
   ```

3. **Откройте меню конфигурации**:
   ```bash
   idf.py menuconfig
   ```
   
   В меню выберите:
   - `Xiaozhi Assistant` → `Board Type` → `Waveshare ESP32-S3-Touch-LCD-1.46`
   - Сохраните и выйдите (S → Enter → Q)

4. **Соберите проект**:
   ```bash
   idf.py build
   ```

5. **Прошейте устройство**:
   ```bash
   idf.py flash monitor
   ```

### Способ 3: Использование скрипта release.py

```bash
python3 scripts/release.py esp32-s3-touch-lcd-1.46
```

Этот скрипт автоматически:
- Установит целевой чип ESP32-S3
- Применит конфигурацию платы
- Выполнит сборку
- Создаст архив с прошивкой

## Прошивка с указанием порта

Если устройство подключено к нестандартному порту:

```bash
idf.py -p /dev/ttyUSB0 flash monitor
# или
idf.py -p /dev/tty.usbserial-* flash monitor  # для macOS
```

## Информация о плате

- **Модель**: Waveshare ESP32-S3-Touch-LCD-1.46
- **Целевой чип**: ESP32-S3
- **Дисплей**: 1.46" Touch LCD (240x320)
- **Конфигурация**: `/main/boards/esp32-s3-touch-lcd-1.46/`

## Дополнительные команды

- **Очистка проекта**: `idf.py fullclean`
- **Только сборка**: `idf.py build`
- **Только прошивка**: `idf.py flash`
- **Мониторинг**: `idf.py monitor`
- **Прошивка + мониторинг**: `idf.py flash monitor`

## Примечания

- Убедитесь, что ESP-IDF версии 5.5.1 или совместимой
- Для прошивки может потребоваться нажать кнопку BOOT на плате
- Проверьте подключение USB-кабеля и драйверы
