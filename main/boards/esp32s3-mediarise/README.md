# ESP32S3-MediaRise

## Описание

ESP32S3-MediaRise - это плата разработки на базе ESP32-S3 с круглым дисплеем 1.28 дюйма, предназначенная для создания робота.

**Характеристики:**
- Микроконтроллер: ESP32-S3
- Дисплей: 1.28 дюйма, круглый, 240x240 пикселей, GC9A01
- Тачскрин: CST816D
- Аудио кодек: ES8311
- Поддержка зарядки батареи
- Уникальный дизайн для робота

**Особенности:**
- Круглый дисплей с поддержкой SimpleDisplay (прямая отрисовка без LVGL)
- Полная поддержка LVGL для расширенного UI
- Управление питанием и энергосбережение
- Мониторинг батареи

## Команды для настройки компиляции

**Настроить цель компиляции для ESP32S3:**

```bash
idf.py set-target esp32s3
```

**Открыть menuconfig:**

```bash
idf.py menuconfig
```

**Выбрать плату:**

```
Xiaozhi Assistant → Board Type → ESP32S3-MediaRise
```

**Выбрать тип дисплея (опционально):**

```
Xiaozhi Assistant → Display Type for ESP32S3-MediaRise
  - Simple Display (Direct drawing, no LVGL) - для простой отрисовки робота
  - LVGL Display (Full UI with LVGL) - для полного UI
```

**Собрать проект:**

```bash
idf.py build
```

**Прошить устройство:**

```bash
idf.py flash monitor
```

## Конфигурация пинов

### Дисплей (SPI)
- SCLK: GPIO4
- MOSI: GPIO2
- CS: GPIO5
- DC: GPIO47
- RESET: GPIO38
- Backlight: GPIO42

### Тачскрин (I2C)
- SDA: GPIO11
- SCL: GPIO7
- RST: GPIO6
- INT: GPIO12

### Аудио
- I2S MCLK: GPIO16
- I2S BCLK: GPIO9
- I2S WS: GPIO45
- I2S DOUT: GPIO8
- I2S DIN: GPIO10
- Codec I2C SDA: GPIO15
- Codec I2C SCL: GPIO14
- PA Pin: GPIO46

### UART для сервоприводов
- TX: GPIO17
- RX: GPIO18
- Скорость: 115200 бод

### Другие
- Boot Button: GPIO0
- LED: GPIO48
- Battery ADC: GPIO1
- Battery Charging: GPIO41

## Управление сервоприводами

Плата поддерживает управление сервоприводами через UART связь с мастер-контроллером.

### Конфигурация UART
- **Порт**: UART_NUM_1
- **Скорость**: 115200 бод
- **TX Pin**: GPIO17
- **RX Pin**: GPIO18

### Формат команд
Команды отправляются в формате `S<номер>:<угол>\n`:
- `S1:45` - установить сервопривод 1 на угол 45°
- `S2:120` - установить сервопривод 2 на угол 120°
- Угол: 0-180 градусов

### Голосовое управление

Робот может управлять сервоприводами через голосовые команды. Доступны следующие MCP инструменты:

1. **`self.robot.set_servo`** - управление отдельным сервоприводом
   - `servo_num`: номер сервопривода (1-10)
   - `angle`: угол поворота (0-180)

2. **`self.robot.set_pose`** - установка позы робота
   - `pose`: имя позы:
     - `home` / `reset` - домашняя поза
     - `wave` / `wave_hand` - махать рукой
     - `dance` / `dancing` - танец
     - `greet` / `greeting` - приветствие
     - `sad` / `sad_pose` - грустная поза
     - `happy` / `happy_pose` - радостная поза

3. **`self.robot.move_servos`** - управление несколькими сервоприводами одновременно
   - `servos`: строка в формате `"S1:45,S2:120,S3:90"`

### Примеры использования

**Голосовая команда:**
- "Помаши рукой" → робот выполнит позу `wave`
- "Покажи танец" → робот выполнит позу `dance`
- "Установи сервопривод 1 на 90 градусов" → робот установит угол

**Автономное управление:**
Робот может сам решать, когда и как управлять сервоприводами, используя MCP инструменты в своих ответах.

## Создание робота

Эта плата предназначена для создания робота. Используйте SimpleDisplay для прямой отрисовки элементов робота (голова, глаза, анимация) или LVGL для более сложного UI. Управление сервоприводами интегрировано с голосовыми командами через MCP.
